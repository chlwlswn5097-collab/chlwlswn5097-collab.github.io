#4. 트러블슈팅 & 의사결정 과정

1) 사진 기록 이탈 방지 UX

  • [문제]
  • 1. 산책 중 사진을 찍고 기록 없이 닫으면 자동 삭제되는데, 사용자가 이를 모른 채 닫기를 눌러 사진을 잃을 수 있음
  • [해결]
  • 1. 닫기 시 ‘기록하지 않으면 사진이 사라집니다. 정말 닫을까요?’ 경고 팝업 노출 → 취소 시 복귀, 닫기 시 이탈
  • [결과]
  • 1. 기존 삭제 정책은 유지하면서도, 사용자가 실수로 사진을 잃는 상황을 방지함

Before - 닫기 누르면 바로 나가짐 (안내 없음)

After - 경고 팝업으로 실수 방지

2) 산책 도중 찍은 사진 기록 상태 구분 UX

  • [문제]
  • 1. '선택' 버튼만으로는 기록 방법이 헷갈림
  • 2. 이미 기록된 사진과 새 사진 구분이 안 됨
  • [해결]
  • 1. 갤러리 상단에 '선택한 사진만 기록됩니다' 안내 문구 배치
  • 2. '선택' 후 '기록하기'가 뜨던 2단계를, 진입 시 CTA 바로 노출로 변경
  • 3. 사진을 업로드 시간순으로 구분하고, 이미 기록 완료된 이전 사진은 비활성화 처리해 현재 장소에서 찍은 사진만 선택 가능하도록 설계
  • [결과]
  • 1. 불필요한 단계를 줄여 선택부터 기록까지 더 빠르고 직관적으로 이어짐
  • 2. 기록 가능한 사진과 이미 기록된 사진이 헷갈리지 않아 중복 선택 방지
  • 3. 갤러리 형식 그대로 시간순 확인이 가능해 흐름이 자연스러움

Before - 기록 흐름과 사진 구분이 불명확

After - 안내 문구와 함께 기록 흐름을 진입 즉시 제공

3) 케어TIP 카드 이동 방식

  • [문제]
  • 1. 케어팁 카드를 눌렀을 때 외부 링크(인스타그램, 블로그 등)로 바로 이동하면, 사용자가 앱을 이탈해 다시 돌아오지 않을 위험이 있음
  • [해결]
  • 1. 카드 터치 시 외부 링크로 이동하지 않고, 앱 내에서 볼 수 있는 페이지로 이동하도록 설계
  • 2. 노데이터 상태를 방지하기 위해 앱 출시 전 콘텐츠를 미리 몇 가지 등록해두는 방식으로 준비
  • [결과]
  • 1. 사용자가 외부로 이탈하지 않고 앱 안에서 콘텐츠를 계속 소비하게 되어, 체류 시간과 앱 내 활동을 유지할 수 있음

4) 산책 메인 안내 문구 다양화

  • [문제]
  • 1. 산책 메인 화면의 안내 문구가 고정되어 있으면 반복 노출 시 지루하게 느껴질 수 있음
  • [해결]
  • 1. 여러 개의 문구를 미리 정해두고, 상황이나 방문 시점마다 다른 문구가 노출되도록 롤링 방식 적용
  • [결과]
  • 1. 여러 개의 문구를 미리 정해두고, 상황이나 방문 시점마다 다른 문구가 노출되도록 롤링 방식 적용
  •    예) “오늘 산책 다녀왔어요, 또 가볼까요?” / “오늘도 함께 걸어볼까요?” 등

#4. 트러블슈팅 & 의사결정 과정

1) 사진 기록 이탈 방지 UX

  • [문제]
  • 1. 산책 중 사진을 찍고 기록 없이 닫으면 자동 삭제되는데, 사용자가 이를 모른 채 닫기를 눌러 사진을 잃을 수 있음
  • [해결]
  • 1. 닫기 시 ‘기록하지 않으면 사진이 사라집니다. 정말 닫을까요?’ 경고 팝업 노출 → 취소 시 복귀, 닫기 시 이탈
  • [결과]
  • 1. 기존 삭제 정책은 유지하면서도, 사용자가 실수로 사진을 잃는 상황을 방지함

Before - 닫기 누르면 바로 나가짐 (안내 없음)

After - 경고 팝업으로 실수 방지

2) 산책 도중 찍은 사진 기록 상태 구분 UX

  • [문제]
  • 1. '선택' 버튼만으로는 기록 방법이 헷갈림
  • 2. 이미 기록된 사진과 새 사진 구분이 안 됨
  • [해결]
  • 1. 갤러리 상단에 '선택한 사진만 기록됩니다' 안내 문구 배치
  • 2. '선택' 후 '기록하기'가 뜨던 2단계를, 진입 시 CTA 바로 노출로 변경
  • 3. 사진을 업로드 시간순으로 구분하고, 이미 기록 완료된 이전 사진은 비활성화 처리해 현재 장소에서 찍은 사진만 선택 가능하도록 설계
  • [결과]
  • 1. 불필요한 단계를 줄여 선택부터 기록까지 더 빠르고 직관적으로 이어짐
  • 2. 기록 가능한 사진과 이미 기록된 사진이 헷갈리지 않아 중복 선택 방지
  • 3. 갤러리 형식 그대로 시간순 확인이 가능해 흐름이 자연스러움

Before - 기록 흐름과 사진 구분이 불명확

After - 안내 문구와 함께 기록 흐름을 진입 즉시 제공

3) 케어TIP 카드 이동 방식

  • [문제]
  • 1. 케어팁 카드를 눌렀을 때 외부 링크(인스타그램, 블로그 등)로 바로 이동하면, 사용자가 앱을 이탈해 다시 돌아오지 않을 위험이 있음
  • [해결]
  • 1. 카드 터치 시 외부 링크로 이동하지 않고, 앱 내에서 볼 수 있는 페이지로 이동하도록 설계
  • 2. 노데이터 상태를 방지하기 위해 앱 출시 전 콘텐츠를 미리 몇 가지 등록해두는 방식으로 준비
  • [결과]
  • 1. 사용자가 외부로 이탈하지 않고 앱 안에서 콘텐츠를 계속 소비하게 되어, 체류 시간과 앱 내 활동을 유지할 수 있음

4) 산책 메인 안내 문구 다양화

  • [문제]
  • 1. 산책 메인 화면의 안내 문구가 고정되어 있으면 반복 노출 시 지루하게 느껴질 수 있음
  • [해결]
  • 1. 여러 개의 문구를 미리 정해두고, 상황이나 방문 시점마다 다른 문구가 노출되도록 롤링 방식 적용
  • [결과]
  • 1. 여러 개의 문구를 미리 정해두고, 상황이나 방문 시점마다 다른 문구가 노출되도록 롤링 방식 적용
  •    예) “오늘 산책 다녀왔어요, 또 가볼까요?” / “오늘도 함께 걸어볼까요?” 등
